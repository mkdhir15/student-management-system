# Student Management System

A beginner-friendly **Student Management System built using Python and Django**.

This project is developed as a practical backend learning project to understand how a Django application works with URLs, views, models, forms, templates, authentication, databases, and CRUD operations.

---

## 📌 About the Project

The Student Management System is a web-based application for managing student records.

### Main Features

- Add Student
- View Student List
- View Student Details
- Edit Student
- Delete Student
- Search Students
- Filter Students by Course
- Display Total Students
- Student Age Validation
- User Authentication
- User Signup
- Protected Views using Login Authentication

The project is intentionally kept simple and practical so that the core Python and Django concepts can be understood clearly.
